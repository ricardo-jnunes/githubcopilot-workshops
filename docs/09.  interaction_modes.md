# Agent Mode
- Definition: Acting as an autonomous peer programmer, it performs multi-step coding tasks at your command — analyzing your codebase, reading relevant files, proposing file edits, and running terminal commands and tests. It responds to compile and lint errors, monitors terminal and test output, and auto-corrects in a loop until the task is completed.

- When to use: scan files, find dependencies, and identify impacted areas, change proposals: generate diffs/patches, edit multiple files, and explain rationale. Run commands/tests: execute build/test/lint commands and report outputs. Iterative fixes: respond to compile/test failures and propose corrections in loops. Task orchestration: decompose work into steps, track progress, and follow a plan. Dev workflow actions (with permission): create branches, prepare commits, and create PRs or review-ready diffs.
- When not to use: To emergency production fixes without review, sensitive-data workflows, or sole decision-maker for security/compliance.
- Benefits: Executes multi-step changes, builds, and tests to reduce manual work.

# Ask Mode

- Definition: Single-turn or iterative conversational Q&A — agent answers, clarifies, or provides snippets on request.
- When to use: quick questions, clarifications, examples, debugging hints, brainstorming, getting one-off code snippets or explanations.
- When not to use: complex multi-step tasks, large refactors, workflows that need sequencing or checkpoints, or when you want the agent to autonomously execute changes.
- Benefits: Fast, low overhead, keeps human fully in control, minimal context/setup required.

# Plan Mode

- Definition: Agent produces a structured, multi-step plan (tasks, order, dependencies) and can track progress or drive an implementation workflow.
- When to use: feature implementation, multi-file changes, release or migration planning, test suites, or any task needing decomposition and checkpoints.
- When not to use: trivial one-off tasks, quick lookups, or when plan overhead would slow down an otherwise simple request.
- Benefits: organizes work, clarifies dependencies, enables staged execution and review, reduces missed steps (breaks work into clear, ordered steps) and enables staged execution and handoffs across teams.
- Practical tip: Start in Ask mode to clarify scope; switch to Plan mode when the task is confirmed as multi-step or requires orchestration.
