# Exercise: Create a Function with GitHub Copilot

In this exercise, you will use GitHub Copilot to create a Python function and generate sample data. You will practice writing a clear prompt, reviewing the generated code, and checking that the result meets the requirements.

## Prerequisites

Before starting, make sure you have:

- A GitHub account with access to GitHub Copilot.
- GitHub Copilot enabled in Visual Studio Code.
- Visual Studio Code installed with the Python extension.
- Python 3.8 or later installed and available in the terminal.
- This repository cloned locally and opened in Visual Studio Code.
- Basic Python knowledge, including functions, parameters, return values, lists, and dictionaries.
- Access to a terminal for running the example.

Verify Python is available by running:

```bash
python --version
```

On some systems, use `python3 --version` instead.

## Learning objectives

By the end of this exercise, you should be able to:

- Describe a function requirement in a prompt.
- Review Copilot's generated code for correctness and readability.
- Run a Python file and verify its output.
- Ask Copilot to generate representative sample data.

## Part 1: Create a temperature conversion function

1. Open `exercises/01. creating-functions/demo.py` in Visual Studio Code.
2. Place the cursor below the existing code and ask Copilot Chat:

	> Create a Python function named `fahrenheit_to_celsius` that accepts a temperature in Fahrenheit and returns the equivalent Celsius value. Use the formula `(fahrenheit - 32) * 5 / 9`, add a type hint and docstring, and do not modify the existing function.

3. Review the suggestion before accepting it. Check that the function:
	- Uses the requested name and parameter.
	- Applies the correct formula.
	- Returns a numeric value.
	- Includes a useful type hint and docstring.
4. Add these checks below the function:

```python
assert fahrenheit_to_celsius(32) == 0
assert fahrenheit_to_celsius(212) == 100
```

5. Run the file:

```bash
python demo.py
```

The file should finish without an assertion error.

## Part 2: Generate and use sample user data

Use Copilot to create a function named `find_user_by_id` that accepts the `users` list and an integer `user_id`. It should return the matching user dictionary, or `None` when no user has that ID.

Use this prompt as a starting point:

> Create a Python function named `find_user_by_id` that searches the existing `users` list by `id`. Return the matching dictionary, or `None` if no user matches. Add type hints and a docstring.

Test the function with:

```python
assert find_user_by_id(users, 1)["name"] == "Alice"
assert find_user_by_id(users, 99) is None
```

Review the generated code and confirm that it does not create a new list or change the existing user records.

## Discussion

Discuss the following questions with the group:

- Which details in the prompt helped Copilot generate the expected function?
- What could go wrong if the return behavior for an unknown ID was not specified?
- How did the assertions help verify the generated code?
- Would you keep the sample data in the same file in a production application? Why or why not?

## Optional extension

Ask Copilot to create a function named `get_users_by_email_domain` that returns all users whose email ends with a specified domain. Test it with `"example.com"` and verify that all five sample users are returned.

## Completion criteria

The exercise is complete when:

- `fahrenheit_to_celsius` converts `32` to `0` and `212` to `100`.
- `find_user_by_id` returns the expected user and returns `None` for an unknown ID.
- The script runs without assertion errors.
- You can explain why you accepted or changed Copilot's suggestions.
