# Exercise: Create a Unit-Test Boilerplate

Create a reusable unit-test template with GitHub Copilot.

1. Choose a function from the workshop project, such as `celsius_to_fahrenheit`.
2. Ask Copilot:

	> Create a unit-test boilerplate for this function using the project's testing framework. Include setup, a successful input, an edge case, and a clear test name.

3. Save the template in the appropriate test folder.
4. Replace the example values with cases for the selected function.
5. Run the tests and confirm that they pass.

**Expected result:** a reusable test template that can be copied for other functions by changing only the function name and test data.
